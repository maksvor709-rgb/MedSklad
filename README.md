# МедСклад PWA

Це комплект саме для застосунку **МедСклад**.

## Файли
- `index.html` — застосунок МедСклад.
- `manifest.webmanifest` — назва, тема та PWA-іконки МедСклад.
- `sw.js` — Service Worker і кешування для офлайн-відкриття.
- `icon-192.png` — іконка 192×192.
- `icon-512.png` — іконка 512×512.

## Завантаження на GitHub
1. Відкрий репозиторій МедСклад на GitHub.
2. Завантаж усі 5 файлів у корінь репозиторію (поруч один з одним).
3. Підтверди Commit changes.
4. Якщо використовується GitHub Pages, перевір у Settings → Pages, що публікація налаштована з потрібної гілки та папки.
5. Відкрий опублікований сайт через HTTPS. Для оновлення встановленої PWA закрий її, відкрий сайт у браузері та перезавантаж сторінку; за потреби видали стару іконку з головного екрана й установи застосунок повторно.

## Важливо
Дані застосунку зберігаються локально в браузері цього пристрою. Перед оновленням або перевстановленням зроби резервну копію даних у самому МедСклад.
