МЕДСКЛАД — чиста версія для початку роботи

Що змінилося:
- При першому запуску каталог порожній: тестових препаратів та операцій немає.
- Інтерфейс адаптований під телефон: нижня панель навігації, великі кнопки та картки.
- Дані зберігаються локально у браузері на цьому пристрої.

Швидкий запуск:
1. Розпакуйте архів.
2. Відкрийте index.html для ознайомлення з основним інтерфейсом.
3. Для встановлення як PWA та доступу до камери запустіть через HTTPS або localhost.
   На комп'ютері з Python 3: python -m http.server 8000
   Потім відкрийте http://localhost:8000
4. На телефоні розмістіть програму на HTTPS-хостингу, відкрийте адресу у браузері та оберіть
   «Додати на головний екран» / «Встановити застосунок».

ВАЖЛИВО:
- Якщо раніше ви вже працювали у тестовій версії на цьому ж браузері, старі дані можуть залишитися
  у його локальному сховищі. Очистіть дані сайту для МедСклад або відкрийте нову версію в іншому
  профілі/браузері, щоб почати з чистого каталогу.
- Регулярно створюйте резервну копію у розділі «Звіти та резерв».
- Камера та PWA-встановлення працюють у безпечному контексті (HTTPS або localhost).
- Це перша робоча версія для практичного випробування; перед використанням у відповідальному
  складському обліку перевірте коректність процесів і резервного копіювання.
